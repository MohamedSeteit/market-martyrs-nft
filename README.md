# MarketMartyrs NFT Collection

**MarketMartyrs** is a generative PFP (Profile Picture) NFT collection deployed and verified on the **Base** blockchain. This repository contains the verified Solidity smart contract, contract ABI, Python metadata generation pipeline, and finalized ERC-721 JSON metadata.
